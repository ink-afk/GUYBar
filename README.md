Discord 上香、任務與世界擴張 Bot。

## 功能
- 每日掃墓（上香）
- 查看世界狀態
- 世界地圖
- 上香排行榜
- 今日任務
- 任務進度
- 固定任務進度
- 隱藏任務與特殊時間 Buff

## 安裝
``bash
git clone https://github.com/你的帳號/GUYBar.git
cd GUYBar
npm install
``echo.
## 設定
在根目錄建立 .env，內容：
TOKEN=你的DiscordBotToken

## 使用
``bash
node index.js
``
